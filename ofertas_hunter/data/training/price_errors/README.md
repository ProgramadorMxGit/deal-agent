# Training fixtures — price errors

Estos JSON son **espejo** de `tests/fixtures/price_errors/`. Se mantienen
duplicados para satisfacer el requisito de la spec §2.1 (carpetas
`tests/fixtures/price_errors/` y `data/training/price_errors/`).

Contienen los ejemplos A-M reales de canales Telegram que el `PriceErrorScorer`
debe clasificar correctamente. La fuente canónica es la copia bajo `tests/`.
Si añades un nuevo ejemplo, agrégalo en `tests/fixtures/price_errors/` y
copia aquí.
